1. What this policy covers

This Privacy Policy explains how Overwatch Intel, an independent Discord application, handles information when you use the bot.

2. Information the bot receives through Discord

When a user interacts with a Discord application, Discord provides the application with information necessary to process the interaction and operate the bot. Depending on Discord's permissions and the interaction, this can include Discord user identifiers, server identifiers, usernames, roles, and interaction metadata.

The current Overwatch Intel bot does not intentionally build user profiles, sell user information, or use Discord API data for advertising.

The current bot does not intentionally store a permanent database of user messages, Discord passwords, payment information, or private conversations.

4. Commands and interaction data

The bot processes the command and options you submit so it can provide the requested response. For example, a hero name may be used to request hero data, and a selected statistics filter may be sent as part of an API request.

The current /ask command uses the question to perform a local lookup against the bot's available hero and map data; it is not intentionally sent to an AI model.

5. Third-party services

To provide Overwatch information, the bot may contact:

  • OverFast API for hero, ability, map, game-mode, and statistics data.
  • Blizzard's official Overwatch website for official news and patch-note links.

These services may receive technical information such as IP addresses as part of normal web requests. Their own privacy policies govern their handling of that information.

6. Data sharing

The operator does not sell Discord API data or provide it to advertising networks or data brokers. Information is disclosed only as necessary to operate the application, comply with law, or respond to valid legal requests.

Política de Privacidad — Overwatch Intel

Última actualización: 7 de octubre de 2026

1. Alcance

Esta Política de Privacidad explica cómo Overwatch Intel, una aplicación independiente para Discord, maneja la información cuando utilizas el bot.

2. Información que recibe el bot mediante Discord

Discord proporciona a las aplicaciones la información necesaria para procesar interacciones y operar el bot. Dependiendo de los permisos y de la interacción, esto puede incluir identificadores de usuario, identificadores de servidor, nombres de usuario, roles y metadatos de la interacción.

El bot actual no crea intencionalmente perfiles de usuarios, no vende información de usuarios y no utiliza los datos de la API de Discord para publicidad.

El bot actual no almacena intencionalmente una base permanente de mensajes de usuarios, contraseñas de Discord, información de pagos o conversaciones privadas.

4. Comandos e interacciones

El bot procesa el comando y las opciones que envías para responder. Por ejemplo, un nombre de héroe puede utilizarse para solicitar información y los filtros de estadísticas pueden formar parte de una solicitud de API.

5. Servicios de terceros

Para proporcionar información de Overwatch, el bot puede comunicarse con OverFast API y con el sitio oficial de Overwatch de Blizzard.

6. Compartición de datos

El operador no vende datos de la API de Discord ni los proporciona a redes publicitarias o corredores de datos. La información solo se comparte cuando sea necesario para operar la aplicación, cumplir la ley o responder a solicitudes legales válidas.

7. Eliminación de datos

Para solicitar la eliminación del ajuste de idioma asociado a un servidor, contacta al operador e identifica el servidor de Discord.

8. Seguridad

Se aplican medidas razonables para proteger los datos almacenados, aunque ningún sistema conectado a Internet puede garantizar seguridad absoluta.

9. Cambios

Esta política puede actualizarse cuando cambien las prácticas de datos del bot. La versión actual permanecerá disponible públicamente en esta URL.
